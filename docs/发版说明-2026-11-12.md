# 发版说明 · 2026-11-12（安卓 0.7.18 / versionCode 25，桌面 0.6.12）

## 本版内容（两大轮、九项）

### 第一轮：界面与曲库管理

1. **配色扩展 + 自定义调色板**：主题与配色拆成两个维度（明暗：深色/浅色/跟随系统 ×
   配色：默认/浅绿/深蓝/粉红/自定义）。三套新配色均含明暗双档完整色板（accent 系 +
   面板同色系偏色）；「自定义」用颜色选择器任选主色，自动派生 hover 色、强调墨色与
   文字黑白（按 WCAG 亮度），存 settings 表双端同步。
2. **一键补封面**：外观面板新入口。后台扫描无封面歌（无缓存 + 无内嵌 + 无 URL 快照）
   → 按「歌名 + 歌手」多源搜索 → 相似度校验（宁缺毋滥，歌手对不上直接跳过）→
   下载后**同时写入本地缓存和音频文件内嵌标签**（mp3/m4a/flac 等六种格式，其它播放器也认）
   → 删 `.miss` 负缓存。带进度/取消/失败列表，绝不覆盖已有封面。
3. **无封面回退改版**：全屏播放页与网格卡大封面显示**整歌名**（居中多行、字号随字数
   自适应、最多 3 行省略）；列表小方块显示前两字；底色三档可换（随机彩色 / 主题色 /
   自定义颜色），文字黑白按背景亮度自动配。
4. **列表歌名滚动**：溢出的歌名 marquee 式滚动。PC 悬停即滚、正在播放行常滚
   （安卓触屏同样常滚），其余行保持省略号不动。
5. **编辑歌名 / 歌手**：右键（PC）/ 长按（安卓）菜单新增「编辑歌名 / 歌手…」。
   保存时**数据库与音频文件标签双写**；按方案约定不改磁盘文件名（目录即歌单模式下
   文件名参与顺序判定与对账）。

### 第二轮：歌单下载

6. **清单解析修复**：`序号,歌名,歌手` 存成 .txt 时曾把逗号带进歌名（如
   `,王子归来,薛之谦`）。现在「数字+逗号」按 CSV 列位切（第 2 列歌名、第 3 列歌手），
   中英文逗号都认；顺带修「2002年的第一场雪」被误剥成「年的第一场雪」的潜伏 bug
   （数字后必须跟分隔符才当序号剥除）。
7. **下载目录 bug 修复**：前端曾总把全局下载目录预填进 `dest_dir`，后端「按目标歌单
   落目录」的分支永远执行不到——新建列表的歌全落到上一层。现在目录模式下**目标歌单
   绑定的文件夹优先**；面板默认「跟随目标列表」，可用「跟随列表」按钮清除自定义目录；
   用户目录与歌单目录不一致时弹提醒。
8. **按源限速**：成功一首歇 3 秒；同一源两次成功间隔不足 30 秒自动补足等待
   （防风控警告导致连续失败）；连续失败指数退避 3→6→…封顶 60 秒（参数
   `LDL_GAP_*` 模块常量）。等待期进度条显示倒计时，随时可取消；「联网重下」分支同套。
9. **歌单补下**：面板新增「跳过目录已有」勾选框（默认开）。开始前扫目标目录
   （标签优先、文件名兜底、跳过 `_回收`，8000 上限）建索引；清单里已有的歌直接跳过
   不联网——**同一份清单反复跑就是断点续传**。匹配稳妥：歌手双方都有但对不上不拦；
   库外文件只跳过不悄悄入库，在库里的顺手加入目标列表。
